# Nervon design system

## Overview
A calm, credible product workspace for Classical Genetics practice. Use a restrained green accent for primary actions, current steps and learning signals.

## Colors
- Page: `#f6f8f6`; cards: white; text: `#20312a`.
- Primary: `#245b43` on white; secondary: `#e9f0eb`.
- Muted text: `#59675f`; border: `#dce3dd`.
- Amber uncertainty states and red errors always include explicit text.

## Typography
Geist sans throughout the product. Fixed rem scale; 14–16 px body copy, 12 px supporting labels, 24–32 px page headings. Course entry alone uses a larger introduction. No decorative display type or animated text.

## Layout and components
72rem maximum content width with 1rem minimum side margins. shadcn Base UI buttons, cards, labels, inputs, textareas, badges, alerts and skeletons. Actions have 44px minimum height; forms use visible labels and unique IDs. Navigation wraps on phones; learning panels become one column. Personal conversation history becomes stacked rows. Reading is progressively disclosed.

## Interaction
Busy forms preserve text and prevent repeated submissions. Visible recoverable errors; uncertainty never looks like success. Reduced-motion support, visible keyboard focus, skip link, screen-reader status updates. Local session reset requires an inline confirmation.
